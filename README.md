# 価値観ゲーム

ブラウザだけで遊べる、2〜8人向けの価値観ゲームです。通常の「数字の順番を当てる」遊びに加え、1人の人狼が並べ替えの失敗を狙う「人狼モード」を収録しています。

## 起動方法

`index.html`、`style.css`、`script.js`を同じフォルダへ置き、`index.html`をブラウザで開いてください。サーバーや外部ライブラリは不要です。

GitHub Pagesで公開する場合は、この3ファイルをリポジトリ直下へアップロードし、リポジトリの「Settings → Pages」で公開元のブランチを選びます。

## ノーマルモード

1. 2〜8人の名前とテーマを設定します。
2. 端末を順番に回し、各自が1〜100の数字を秘密で確認します。
3. 数字を直接言わず、テーマに合う答えを発表します。
4. 答えを手がかりに、数字が大きい順へ並べます。
5. 正解の順番と数字を確認します。

例：テーマが「もらってうれしいプレゼント」、数字が90なら「最新のゲーム機」、数字が15なら「知らない人のサイン」のように答えます。

## 人狼モード

1. 3〜8人のうち、ランダムで1人が人狼になります。
2. 市民と人狼の全員に、重複しない1〜100の数字が表示されます。
3. 市民は正しい並び順を目指し、人狼は正体を隠しながら並べ替えの失敗を狙います。
4. 全員を並べた後、妨害したと思う1人へ投票します。
5. 並び順と人狼投票を合わせて勝敗を判定します。

## 人狼モードの勝敗

| カード並べ | 人狼投票 | 勝者 |
| --- | --- | --- |
| 成功 | 当たり・外れに関係なし | 市民 |
| 失敗 | 人狼を当てた | 市民（逆転勝利） |
| 失敗 | 人狼を外した | 人狼 |

つまり、人狼が勝つには「カード並べを失敗させる」と「投票で見破られない」の両方が必要です。

## 改善した操作

- 最初の画面で2モードを選択
- スマホ・Chromebook対応のレスポンシブ表示
- ドラッグに加え、▲▼ボタンで確実に並べ替え
- 個人カード表示前に「端末を渡す」画面を追加
- プレイヤー名の重複チェック
- 人数変更時に入力済みの名前を保持
- ランダムテーマ12種類と「おまかせ」ボタン
- やり直し時の確認画面
- 完全一致と一致人数を結果表示

## 補足

- データは外部へ送信されません。ゲームを閉じると内容は消えます。
- 1台の端末を順番に回して遊ぶ設計です。
- 人狼モードは、会話が成立しやすい4〜6人を推奨します。
